
# Library Book Management API

A REST API developed using Node.js and Express.js for managing library books.

## Technologies
- Node.js
- Express.js
- Postman

## Features
- GET all books
- POST a new book
- GET book by ID
- PUT to update a book
- DELETE a book
- Filter books by author

## Setup Instructions

1. Clone this repository.
2. Open the project folder.
3. Install dependencies:

   npm install

4. Start the server:

   npm start

## Server
http://localhost:3000

## Data Storage
Records are stored in an in-memory JavaScript array. No external database is used.
